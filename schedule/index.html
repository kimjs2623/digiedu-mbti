부팅 시 자동 실행 설정

Windows 사용자 방법:

  1. 단축키 Win + R 키를 누릅니다.
  2. 입력창에 shell:startup 입력 후 확인을 누릅니다.
  3. 열린 폴더 안에 이 index.html 파일의 바로가기를 만들어 넣습니다.

Mac 사용자 방법:

  1. [시스템 설정] > [일반] > [로그인 항목]으로 이동합니다.
  2. [로그인할 때 열기] 목록 아래의 + 버튼을 누릅니다.
  3. 이 index.html 파일을 찾아서 등록합니다.
